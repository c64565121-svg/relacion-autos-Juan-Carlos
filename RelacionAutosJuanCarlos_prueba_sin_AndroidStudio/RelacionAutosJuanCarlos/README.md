# Relación de los Autos Juan Carlos

Proyecto Android en Kotlin.

Funciones incluidas:
- Pantalla completa.
- Cámara con CameraX.
- OCR con Google ML Kit.
- Detección de VIN/chasis de 17 caracteres.
- Detección básica de modelo y año cuando aparecen en la placa.
- Modelo editable manualmente si la foto solo contiene el chasis.
- Ficha vehicular.
- Base de datos Room.
- Inventario y búsqueda.
- Generación de archivo DOCX con datos y fotografía.
- Permiso de Internet preparado para la futura sincronización por red.

Abrir la carpeta en Android Studio y sincronizar Gradle.
